# 🎙️ AI 유튜브 다국어 목소리 더빙 웹사이트 스튜디오 (Chatterbox Multilingual)

유튜브 영상 링크를 입력하면 원본 화자의 고유 목소리를 학습/복제하여 **11개 국어**(영어, 일본어, 중국어, 힌두어, 아랍어, 프랑스어, 독일어, 스페인어, 히브리어, 튀르키예어, 말레이어)로 자동 번역 및 더빙 음성/영상을 생성하고, 다운로드 가능한 형태로 제공하는 **풀스택 웹 애플리케이션**입니다.

---

## 🌟 웹사이트 주요 기능 & UI 화면

1. **🔗 스마트 유튜브 링크 파싱 (`yt-dlp`)**
   - 링크 입력 시 썸네일, 제목, 재생시간, 업로더 정보를 실시간으로 확인.
2. **🎙️ 목소리 추출 구간 제어 (슬라이더)**
   - 내 목소리가 나오는 시작점(0~60초)과 길이(10~30초)를 조절하여 최적의 24kHz 모노 음성 샘플 추출.
3. **🌐 11개 국어 인터랙티브 카드 그리드**
   - 국기 이모지와 함께 11개 국어를 개별/전체 원클릭 토글.
   - 영어(🇺🇸), 일본어(🇯🇵), 중국어(🇨🇳), 힌두어(🇮🇳), 아랍어(🇸🇦), 프랑스어(🇫🇷), 독일어(🇩🇪), 스페인어(🇪🇸), 히브리어(🇮🇱), 튀르키예어(🇹🇷), 말레이어(🇲🇾).
4. **📊 실시간 진행 상황 모니터링**
   - 0~100% 프로그레스 바 및 실시간 터미널 로그 창 탑재.
5. **🎧 다국어 플레이어 & 다운로드 쇼케이스**
   - 추출된 내 목소리 샘플 재생기.
   - 초 단위 STT 자막(SRT) 표 및 다운로드.
   - 언어별 탭 전환식 플레이어:
     - 🔊 **생성된 더빙 음성** 듣기 + `WAV` 다운로드
     - 🎬 **더빙 합성 영상** 보기 + `MP4` 다운로드
     - 📝 **번역 스크립트** 확인
   - 📦 **모든 결과물 일괄 다운로드 (`.ZIP`)** 버튼 제공.

## 🚀 웹사이트 실행 방법 (원클릭)

### 방법 1. 배치 파일 더블클릭 (가장 간편)
폴더 내의 **`run_website.bat`** 파일을 더블클릭하세요.
자동으로 로컬 서버가 구동되고 기본 웹 브라우저(`http://localhost:8000`)가 열립니다.

### 방법 2. 터미널에서 실행
```powershell
.\.venv\Scripts\python.exe server.py
```
실행 후 브라우저에서 `http://127.0.0.1:8000`으로 접속하시면 됩니다.

## 📁 주요 코드 구조

- `server.py` : FastAPI 기반 비동기 웹 서버 (REST API & 웹페이지 서빙)
- `templates/index.html` : 반응형 모던 글래스모피즘 웹 프론트엔드 (Tailwind CSS)
- `static/app.js` : 비동기 통신, 상태 폴링, 오디오/비디오 플레이어 제어 스크립트
- `downloader.py` : yt-dlp 영상/오디오 다운로드 및 24kHz 모노 목소리 추출
- `stt_transcribe.py` : Faster-Whisper 기반 초 단위 STT 음성인식 및 SRT 생성
- `translator.py` : 11개 언어 번역 엔진 및 일본어 발음 최적화(`pykakasi`)
- `voice_synthesizer.py` : ChatterboxMultilingualTTS 음성 복제 및 FFmpeg 영상 합성
- `pipeline.py` : 전체 파이프라인 자동화 및 ZIP 압축 패키징
- `run_website.bat` : 더블클릭 원클릭 실행 스크립트
